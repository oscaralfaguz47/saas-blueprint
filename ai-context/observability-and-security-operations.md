# Observability and Security Operations

## Purpose

Defines monitoring, logging, and incident detection practices.

---

# Core Rules

## 1. Security Logging

Security-relevant events must be logged.

Examples:

- failed login attempts
- permission denials
- suspicious activity

---

## 2. Alerting

Critical anomalies should trigger alerts.

Examples:

- repeated login failures
- abnormal API usage
- suspicious access patterns

---

## 3. Incident Response

The system must support investigation through:

- audit logs
- request logs
- activity logs
